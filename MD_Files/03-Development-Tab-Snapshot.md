# Development Tab Snapshot (Legacy)

## Status

- `Development` is a legacy navigation model and is not a canonical top-level tab.

## Legacy routes

- `/development`
- `/development/:section`

## Redirect behavior

- `/development` redirects to `/military-service`.
- `/development/military-service` redirects to `/military-service`.
- `/development/service-treatment-records` redirects to `/service-records`.
- `/development/current-treatment` redirects to `/current-treatment`.

## Canonical replacements

1. Military Service: `/military-service`
2. Service Treatment Records: `/service-records`
3. Current Treatment: `/current-treatment`
