# Benefits Advisory

## Purpose
Provide financial-legal advisory insights using the existing benefits logic.

## Actions
- Calculate federal, state, combat, exposure, and retirement benefits.
- Provide scenario modeling (e.g., rating changes).
- Show stacking rules and eligibility pathways.
- Present monthly and long-term financial impact.

## Responsibilities
- Federal benefits
- State benefits
- Combat/exposure benefits
- Retirement benefits
- Scenario modeling
- Financial projections
