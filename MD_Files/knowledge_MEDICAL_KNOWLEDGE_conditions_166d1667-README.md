# Radiation Exposure Presumptive Conditions

This directory contains data on conditions presumed to be caused by ionizing radiation exposure.

## Data Files
- `conditions.json` - Complete list of 20 presumptive cancers and exposure categories

## Eligible Exposures
- Atomic Veterans (atmospheric nuclear testing 1945-1962)
- Hiroshima/Nagasaki occupation forces (1945-1946)
- Gaseous diffusion plants workers
- Nuclear weapons testing participants
- Enewetak Atoll cleanup (1977-1980)
- Nuclear reactor exposure
- X-ray technicians

## Presumptive Cancers (20 types)
- Leukemia (except CLL)
- Multiple solid cancers (brain, breast, colon, lung, thyroid, etc.)
- Salivary gland, bile duct, stomach, pancreas, and more

## Special Requirements
- Latency periods vary by cancer type (1-5 years minimum)
- Radiation dose must be established as positive
- Dose reconstruction available through DTRA

See `conditions.json` for complete details on latency periods and requirements.
