# Dashboard

## Purpose
Provide a consulting-grade overview of the veteran’s claims, evidence, risks, and opportunities.

## Actions
- Pull summary data from intelligence, benefits, and scanner engines.
- Display high-level insights and trends.
- Surface risks, opportunities, and next steps.
- Show recent scans and AI insights.

## Responsibilities
- Claims overview
- Evidence completeness
- Rating projections
- Recent scans
- Action items
- AI insights
