# Scanner Hub

## Purpose
Serve as the unified document intelligence center.

## Actions
- Accept uploads (PDF, STRS, VA decisions, images).
- Call existing scanner endpoints.
- Display structured results (evidence, conditions, ratings, payments, SMC, dependents).
- Highlight missing evidence and recommendations.
- Show CFR-aligned reasoning where available.

## Responsibilities
- Upload panel
- Scan status
- Evidence extraction
- Missing evidence
- CFR reasoning
- Recommendations
