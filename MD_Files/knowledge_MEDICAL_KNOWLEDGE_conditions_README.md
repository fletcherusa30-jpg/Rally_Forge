# Agent Orange Presumptive Conditions

This directory contains comprehensive data on conditions presumed to be caused by Agent Orange and other herbicide exposures during military service.

## Data Files
- `conditions.json` - Complete list of 18 presumptive conditions with diagnostic codes, effective dates, and requirements

## Coverage
- Vietnam War era (1962-1975)
- Korean DMZ (1968-1971)
- Thailand military bases (1961-1975)
- C-123 aircraft crew members

## Key Conditions
- Type 2 Diabetes
- Ischemic Heart Disease
- Parkinson's Disease
- Respiratory Cancers
- Prostate Cancer
- Multiple cancers and blood disorders

See `conditions.json` for complete details including evidence requirements and regulatory references.
