# VA Claims Process
This section explains the full lifecycle of a VA disability claim.

## Core Concepts
- Initial claim filing
- Evidence gathering
- C&P exams
- Rating decisions
- Duty to assist

## Required Data Fields
- Claim type
- Evidence list
- Medical conditions
- Service periods
