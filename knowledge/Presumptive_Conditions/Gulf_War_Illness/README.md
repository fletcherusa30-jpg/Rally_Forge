# Gulf War Illness / Chronic Multisymptom Illness

This directory contains data on Gulf War Illness and chronic multisymptom illnesses affecting Gulf War veterans.

## Data Files
- `conditions.json` - Comprehensive coverage of medically unexplained illnesses and infectious diseases

## Coverage
- Service dates: August 2, 1990 - present (ongoing)
- Locations: Southwest Asia Theater including Iraq, Kuwait, Saudi Arabia, Persian Gulf, and surrounding areas

## Qualifying Illnesses
### Chronic Multisymptom Illness (5 categories)
- Chronic Fatigue Syndrome
- Fibromyalgia
- Functional GI Disorders
- Medically Unexplained Chronic Multisymptom Illness
- Undiagnosed Illness

### Infectious Diseases (9 diseases)
- Brucellosis, Q Fever, Malaria, Tuberculosis, West Nile Virus, and more

## Special Features
- No specific diagnosis required for "undiagnosed illness"
- Symptoms must be chronic (6+ months)
- No time limit for manifestation

See `conditions.json` for complete symptom categories and requirements.
