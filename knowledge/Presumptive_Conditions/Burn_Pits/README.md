# Burn Pits & Airborne Hazards Presumptive Conditions

This directory contains data on conditions presumed to be caused by burn pit exposure and airborne hazards under the PACT Act.

## Data Files
- `conditions.json` - Complete list of 27 presumptive conditions (23 added by PACT Act)

## Coverage
- Southwest Asia Theater (1990-present)
- Afghanistan (2001-present)
- Gulf War locations including Iraq, Kuwait, Saudi Arabia, UAE, and others

## Key Conditions
### Respiratory (13 conditions)
- Asthma, Chronic Bronchitis, Emphysema, Pulmonary Fibrosis, Sarcoidosis, and more

### Cancers (14 conditions)
- Brain Cancer, GI Cancers, Head/Neck Cancer, Kidney Cancer, Lymphoma, Melanoma, Pancreatic Cancer, and more

See `conditions.json` for complete details.
