# TERA Database

Contains TERA program eligibility criteria, requirements, and reference data.

## Files

- `tera_eligibility.json` - Complete TERA eligibility requirements
  - Program overview and authority
  - Basic requirements (15-20 years service)
  - Branch-specific criteria (Army, Navy, Air Force, Marine Corps)
  - Disqualifying factors
  - Retirement calculation formulas and examples
  - Benefits and limitations
  - Application process (9 steps)
  - Financial, healthcare, career, and personal considerations
  - Official resources and calculators

## Data Coverage

- All service branches (Army, Navy, Air Force, Marine Corps, Space Force, Coast Guard)
- Eligibility years: 15-19.99 years of service
- Retirement multiplier: 2.5% per year
- Application process and timeline
- Comparison to 20-year regular retirement
