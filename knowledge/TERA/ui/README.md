# TERA Calculator UI Components

User interface components for TERA retirement calculator.

## Planned Components

- Input form for service record data
- Eligibility checker widget
- Calculation results display
- Comparison chart (TERA vs 20-year retirement)
- COLA projection graph
- SBP calculator widget
- Export to PDF functionality

## Technologies

- React components for integration with Rally Forge UI
- Chart.js for data visualization
- Form validation using calculation schema
