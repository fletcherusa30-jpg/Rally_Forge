# Retirement Planner Logic Layer

This folder contains all cross-platform business logic for the Retirement Planner module.

## Includes:
- Future value math engines (PowerShell, JS, Dart, Swift)
- Scenario engine (best/median/worst)
- Validation rules
- Configurable scenario presets

This logic layer is UI-agnostic and shared across:
- React
- Flutter
- SwiftUI
- Backend services
